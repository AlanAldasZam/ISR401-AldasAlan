## Cómo compilar

- Compilador: pdfLaTeX con BibTeX.
- Archivo principal de cada actividad: `main.tex`, dentro de su carpeta.
- Orden de comandos (desde la carpeta de la actividad):

```
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

- Dependencias: una distribución LaTeX con los paquetes `inputenc`, `fontenc`, `babel` (español), `geometry`, `array`, `longtable`, `hyperref` y el estilo bibliográfico `IEEEtran` (incluidos en TeX Live y MiKTeX). También compila en Overleaf con el compilador pdfLaTeX.
